## Problem / Context

Following the monorepo merge and the renames (repo `akds-portfolio-2026` to `akds`,
`apps/studio` to `apps/design`), a few things in the repo no longer match reality:

- `.gitignore` still has the CRA/Next template's yarn/pnp/pnpm lines, and `out/`,
  even though this is npm-only and every app exports to `build/`.
- The deploy docs are out of date. GitHub check-runs on `ecffe20` show the Pages
  projects are **`akds-portfolio`** (akds-portfolio.pages.dev, which 301s to
  akds.dev) and **`akds-design`** (akds-design.pages.dev, deploying successfully
  from `main`). `akds-portfolio-2026.pages.dev` does not resolve. The docs call the
  portfolio project `akds-portfolio-2026` and call the design deploy "deferred".
  The root doc also mentions an "analytics token env", but nothing reads one: the
  beacon is edge-injected (see apps/portfolio/CLAUDE.md). "Branches never deploy"
  is also wrong, because branches get Pages preview URLs. Production is the only
  thing tied to main.
- `.mcp.json` uses the `cloudflare-graphql` MCP, which now announces itself as
  deprecated in favour of `https://mcp.cloudflare.com/mcp`.

Already done locally (not part of the diff): `npm ci` to create the `@akds/*`
workspace links; removed the old `../akdsdesign` clone and stale root `.next/`,
`next-env.d.ts` and `tsconfig.tsbuildinfo`.
